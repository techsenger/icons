# Techsenger Icons

Techsenger Icons is a collection of additional icons created to complement third-party icon sets used in
Techsenger projects. The goal of this project is not to create a new icon font or replace existing icon sets, but
to provide missing icons that are needed in our applications.

The icons included in this project are independently created and are not part of the official icon sets they
complement. Techsenger Icons is not affiliated with or endorsed by the authors of the original icon sets.

## Features <a name="features"></a>

Key features include:

* Additional icons for existing popular icon sets.
* SVG and font-based icon support.
* Simple integration with existing icon libraries.

## Icon Sets <a name="icon-sets"></a>

Currently, Techsenger Icons provides additional icons for [Pictogrammers Material Design Icons](https://pictogrammers.com/library/mdi/).
The included icons are designed to complement the original icon set and cover missing icons required by Techsenger projects.

## Usage <a name="usage"></a>

All icons are provided in SVG format. They are also combined into TTF fonts, which can be integrated into applications in the same way as any other custom font.

The latest generated TTF fonts can be downloaded from the Artifacts section of the latest successful [GitHub Actions](https://github.com/techsenger/icons/actions) workflow run.

## Code Building <a name="code-building"></a>

Each icon set extension is generated using dedicated scripts located in the corresponding extension directory. Instructions on how to run these scripts are provided in the header comments of each script.

## License <a name="license"></a>

Each icon set extension has its own license, which corresponds to the license of the original icon set it extends. Please refer to the license file located in the corresponding extension directory for detailed information.
